Insights

Value measurement

How we measure AI value

Every AI use is counted once, with the hours fixed per use case. So savings and ROI add up the same way in every team.

Read more
Savings = hours per use × uses
ROI = Savings ÷ Investment

An AI committee sets the hours per use once. Users only tap. Guards catch back-dating, double counting and over-reporting, and every number can be traced to the use that made it.

Method

The Team Digital Twin

A map of every activity a team does, weighted by its share of the week. It shows where AI helps today, and where it should help next.

Read more
Team Digital Twin = Σ linked use cases
Use case = Pain × Gain × AI fit

Twin coverage is the share of a team’s weighted work that AI really covers. We refresh each Twin every six months, so the plan follows how the work changes.
